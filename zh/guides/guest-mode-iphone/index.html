Lockstead / 使用指南

借出 iPhone 前如何使用 Lockstead 访客模式

访客模式用于把同一台设备暂时借给别人。VIP 用户可以选择访客可用的应用，在访问期间限制其他应用。

操作步骤

  1. 打开 Lockstead，以 PIN 或已配置的生物识别认证。
  2. 选择访客需要使用的应用，将清单限制在本次借用用途内。
  3. 启动访客模式，检查状态与时长。
  4. 借出前分别测试一个允许应用和一个被阻止应用。
  5. 访问结束后重新打开 Lockstead，核对预期保护规则已恢复。

需要了解

访客模式是本机流程，不是远程监管另一台手机。某些系统行为不受应用控制。保管好管理 PIN，通过实际检查确认保护，不要只依赖倒计时。
